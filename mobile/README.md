📱 7. Application Mobile
    Objectif
    Offrir aux utilisateurs une expérience fluide sur mobile, avec suivi de course en temps réel, visualisation des performances, et accès à l’historique des sessions sportives.

🔐 Authentification
Fonctionnalités disponibles :

Inscription : création d’un nouveau compte avec email et mot de passe.

Connexion : vérification des identifiants et redirection vers l’accueil.

Mot de passe oublié : réinitialisation du mot de passe via email sécurisé.

🏠 Page d’Accueil
Éléments affichés :

Résumé des données principales (ex : distance totale, calories brûlées, nombre de courses).

Graphique dynamique basé sur les performances récentes de l’utilisateur (mise à jour en temps réel ou après synchronisation).

🏃‍♂️ Course en Temps Réel
    Fonctionnalités clés :

    Interface dédiée à la course : démarrage, pause, arrêt de la session.

    Géolocalisation en direct : suivi GPS constant pendant la course.

    Tracé du parcours sur une carte interactive (intégration Google Maps / Mapbox).

📜 Historique
    Fonctionnalités implémentées :

    Liste complète des courses passées.

    Affichage détaillé par course (distance, durée, calories, vitesse moyenne, etc.).

    Possibilité de cliquer sur une course pour consulter le tracé du parcours et les statistiques associées.

📌 L’application mobile vient compléter l’interface web en permettant un suivi terrain en temps réel, avec synchronisation des données vers le dashboard central.
